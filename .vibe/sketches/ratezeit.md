# Skizze RateZeit (S. passwort, 360 px)

```
Länge: 8 Zeichen          [――――●――――――――――]  (4 … 24)
Zeichenarten:  [x] kleine Buchstaben (26)  [ ] große Buchstaben (26)
               [ ] Ziffern (10)            [ ] Sonderzeichen (33, Annahme)

Zeichenvorrat:        26
Mögliche Passwörter:  26^8 ≈ 209 Milliarden
Ratezeit*:            im Mittel etwa 10 Sekunden
[■■■□□□□□□□□□□]  Sekunden · Stunden · Jahre · Jahrtausende

* Annahme dieser App: ein Rechner probiert 10 Milliarden Passwörter pro Sekunde.
  Im Mittel findet er das richtige nach der Hälfte. Du tippst hier kein Passwort ein.
```

Schritte: Start 8 Zeichen, nur Kleinbuchstaben. Regler auf 12 → Zeit springt auf Jahre. Zurück auf 8, alle vier
Zeichenarten → Zeit steigt, aber weniger als mit 4 Zeichen mehr.
