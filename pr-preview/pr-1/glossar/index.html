Glossar

Die Begriffe dieser App, von A bis Z, jeder mit der Seite, die ihn erklärt.

Datei

Eine Datei ist ein gespeichertes Stück Daten mit einem Namen, zum Beispiel ein Foto, ein Lied oder ein Text. In einer Datei liegt kein Ordner, darum ist sie im Baum ein Blatt.

Erklärt auf der Seite Ordner und Dateien

Dateiendung

Die Endung ist der letzte Teil des Dateinamens, nach dem Punkt. Sie zeigt die Art der Datei, zum Beispiel .jpg für ein Foto, .mp3 für etwas zum Hören, .txt für einen Text. Im Baum steht sie unten.

Erklärt auf der Seite Ordner und Dateien

Ordner

Ein Ordner ist ein Platz mit Namen. Darin liegen Dateien und weitere Ordner, die zusammengehören.

Erklärt auf der Seite Ordner und Dateien
